# 拯救张雪峰

像素风格的 Flappy Bird 小游戏：操控张雪峰老师穿过土木柱子，尽量拿到更高分数。

## 直接游玩

下载 Release 中的 `zhangxuefeng_flappingbird_v1.0.zip`，解压后双击 `release.exe` 即可运行。

## 操作方式

### 键盘与鼠标

- 空格键：向上飞
- 鼠标：操作菜单、翻页与确认

### Xbox 手柄

- 左摇杆 / 十字键：选择开始菜单项目
- A：确认、起飞、失败后再来一次
- B：从教程或作者页返回；取消清除记录
- X：在志愿填报指南中清除历史记录
- LB / RB：在志愿填报指南中翻页
- Start：在志愿填报指南开始游戏，或在失败后重新开始

## 游戏内容

- 三条生命与受伤后的短暂无敌
- 雪碧道具：恢复一条生命
- 巧乐兹道具：触发雪峰冲刺
- 计分、音效、飞行动效与失败螺旋动画
- 志愿填报指南：保存每局成绩并给出对应去向

## 本地构建

项目基于 C++17 与 SFML 2.6.2。Windows 下使用 MinGW 编译；运行发行版时，`release.exe` 必须与同目录的 SFML DLL、`openal32.dll` 和 `assets` 文件夹放在一起。
